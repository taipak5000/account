# アカウント管理（サブキャンドル管理）

Skyのサブアカウントごとにキャンドル数を記録・管理する、単一HTMLファイルの小さなWebアプリです。
`index.html` をブラウザで開くだけで使えます（GitHub Pages等に置いてもそのまま動きます）。

## 使い方

- **登録**：アカウント名（必須）・機種・グループ・キャンドル数を入力して「アカウントを追加」。
  機種とグループは、登録済みの値が候補（入力補助）として出ます。
- **個別変更**：一覧の数値は直接書き換えられます。−／＋ボタンでも1本ずつ増減できます。
- **一括変更**：全体またはグループを選んで +2 / −6 のショートカット、または任意の数値を適用。
  適用直後はトーストの「元に戻す」で取り消せます。
- **探す・並べる**：グループチップ（件数・小計つき）で絞り込み、検索欄で名前・機種・
  グループを横断検索、上部のプルダウンで「キャンドル多い順」などに並べ替えできます
  （並べ替えは表示だけで、保存されている順番は変わりません。手動の▲▼は「手動の並び順」
  のときに使えます）。
- **テーマ**：右上のボタンでダーク／ライトを切り替えられます（未設定時は端末の設定に従います）。

## データについて

- データはブラウザのローカルストレージ（キー `ios_account_manager_data_v3`）に保存され、
  外部に送信されることはありません。保存形式は旧バージョンと同一で、旧データは
  そのまま引き継がれます。
- 端末やブラウザを変えるとデータは引き継がれないため、「データのバックアップ」から
  JSONファイルに書き出して保管してください。読み込み（復元）は、旧バージョンで
  書き出したファイルとも互換性があります。
- 画面の好み（テーマ・並び順・フィルター）は別のキー `subcandle_ui_v1` に保存され、
  本体データとは混ざりません。
